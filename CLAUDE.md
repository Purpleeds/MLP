# MLP — Floating lyrics for Windows

Tauri 2 desktop app: always-on-top, draggable, rounded, opaque floating window + tray icon near the clock. Follows Spotify / YouTube Music (Windows GSMTC), shows LRCLIB synced lyrics with Apple-Music-style word fill, romanization (romaji / pinyin / Korean RR / any-ascii), display modes, full settings.
Full plan with per-step checklists: **PLAN.md**. Reference look: `docs/ref/` (Apple Music ×2, YouTube Music).

## Architecture (short)
- Rust (`src-tauri/`) = thin native layer: GSMTC, JapanesePhoneticAnalyzer, tray, window, fonts, extension bridge.
- TS (`src/`) = all app logic: lyrics provider, parsing, timing, romanization, renderer, settings. Unit tests with vitest.
- Mock mode: running outside Tauri (plain browser) → fake track / clock / lyrics, for UI work in the built-in browser.
- Custom renderer. AMLL rejected (AGPL-3.0, pixi deps, few styling hooks) — behavior reference only, never copy its code.

## Verified facts (2026-11-15)
- Hardware: NVIDIA RTX 5060 Ti 16 GB (Blackwell → CUDA 12.8+), 32 GB RAM, 28 threads.
- Toolchain: Node 24.18 / npm 12, Rust 1.99.1 (rustup, MSVC), VS 2022 Community + VC tools, WebView2 157, git 2.55, winget. No pnpm / bun.
- LRCLIB: `GET /api/get` (track_name, artist_name required; album_name, duration optional; ±2 s) · `/api/get/{id}` · `/api/search` (q or track_name; ≤ 20 results). Fields: id, trackName, artistName, albumName, duration, instrumental, hasWordSync, plainLyrics, syncedLyrics, lyricsfile (YAML; `lines[].words` when hasWordSync). Identify via User-Agent or `Lrclib-Client` / `X-User-Agent`. CORS `*` allows `lrclib-client` header → plain `fetch` works in WebView/browser. `syncedLyrics` often contains enhanced `<mm:ss.xx>` word stamps even when hasWordSync=false; lyricsfile words may be whole-line (coarse). ~45 req/min anon, ~90 identified; 429 → Retry-After + jitter; sequential, 200–500 ms apart.
- Chromium DOES publish the SMTC timeline (tested 2026-11-16 via Electron pane + YouTube: duration, position, LastUpdatedTime, seeks all update; position only on events → extrapolate). YouTube: title "Artist - Song (Official Video)", artist = channel, album empty.
- JapanesePhoneticAnalyzer: STA-only class and returns EMPTY on this PC (no Japanese language pack) → not used; Lindera 6.2 `embedded://ipadic` instead (details[7] = katakana reading).
- kuromoji under Vite: `.gz` dictionary corruption issues → avoided.
- Tauri on Win11: shadow and rounded corners are coupled; `shadow:false` + transparent may still show a border on some versions.
